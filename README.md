# Burguer Express

[🇧🇷 Português](#português) | [🇺🇸 English](#english)

---

## Português

Landing page e fluxo interativo de pedidos para uma hamburgueria artesanal, desenvolvida com foco em layout responsivo, clareza visual e manipulação de DOM com JavaScript.

### Tecnologias utilizadas
- HTML5
- Tailwind CSS
- JavaScript (Vanilla JS)

### Funcionalidades
- Apresentação institucional e destaque do hambúrguer principal da casa.
- Cardápio com seleção rápida de itens que preenche automaticamente o formulário de pedido.
- Geração dinâmica do resumo do pedido com nome do cliente, item escolhido e observações.

---

## English

Responsive landing page and interactive order flow for an artisanal burger restaurant, built with a focus on clean visual hierarchy, mobile-first layout, and DOM manipulation with JavaScript.

### Tech Stack
- HTML5
- Tailwind CSS
- JavaScript (Vanilla JS)

### Features
- Brand showcase and featured signature burger section.
- Interactive menu cards that automatically pre-fill the order form upon selection.
- Dynamic order summary generation displaying customer details, selected item, and custom notes.
